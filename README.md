# 🛒 Lista de Compras

Este é um projeto simples de **Lista de Compras** feito com HTML, CSS e JavaScript. Com ele, você pode adicionar, riscar e excluir itens da sua lista, além de limpá-la por completo.

## 🚀 Funcionalidades

- ✅ Adicionar novos itens à lista
- ✅ Marcar itens como concluídos
- ✅ Excluir itens individualmente
- ✅ Limpar toda a lista
- ✅ Interface responsiva e amigável

## 🖼️ Layout

A interface é simples e adaptada para dispositivos móveis, com um design limpo e intuitivo.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (puro)
